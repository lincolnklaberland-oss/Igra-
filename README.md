# Айдар и Альфина — Android prototype

Это стартовый Android-проект на Java: горизонтальная 2D-игра с сенсорными кнопками, Айдаром, врагами и Альфиной у замка.

## Как запустить и собрать APK
1. Установи Android Studio на компьютер.
2. Открой Android Studio → Open и выбери папку `AidarAlfinaAndroid`.
3. Дождись Gradle Sync и установи предложенные Android SDK (compile SDK 35).
4. Подключи Android-телефон с включённой USB debugging либо запусти эмулятор.
5. Нажми Run ▶ для запуска.
6. Чтобы получить APK: Build → Build Bundle(s) / APK(s) → Build APK(s). Android Studio покажет путь к APK.

Примечание: здесь подготовлен исходный проект, а не уже собранный APK. Для сборки нужен Android Studio/Android SDK.


## Сборка APK через GitHub с телефона

1. Создай новый репозиторий на GitHub и загрузи файлы проекта из распакованного ZIP.
2. Открой вкладку **Actions** и разреши запуск workflows, если GitHub спросит.
3. После загрузки в ветку `main` сборка запустится автоматически. Её можно запустить вручную через **Actions → Build Android APK → Run workflow**.
4. Открой завершённый запуск, найди **Artifacts** и скачай `aidar-alfina-debug-apk`.
5. Распакуй скачанный архив и нажми `app-debug.apk`, чтобы установить. Android может попросить разрешить установку из этого источника.

Это тестовая debug-сборка. APK появится только после успешного завершения сборки; если сборка завершится ошибкой, проект придётся исправить.
